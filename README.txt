GIT 337 FINAL CAPSTONE DOCUMENTATION STARTER

This is a concise evidence template, not a website starter.

1. Build the three- or four-page capstone in your own GitHub repository.
2. Replace every bracketed prompt in capstone-evidence.html.
3. Add only the table rows needed to cover the requirements and three findings.
4. Insert two or three labeled screenshots.
5. Export the completed page as one PDF.
6. Click every URL in the PDF before submitting it to Canvas.

For the Practice checkpoint, complete Sections 1–4 with a working draft, three findings, and at least one repair/retest.
For the final Deliverable, revise all six sections and include the final URLs and results.
